AstroloAI — End-to-End Architecture Flow

Query → Router → Chart Math → Prediction → Reconciliation → Output  ·  E:\ASTROLOGY AI
STEP 1 User Query Arrives
app.py → POST /api/chat
"Will I get a promotion in 2027?" arrives with a session_id. FastAPI calls run_astrologer() from ai_agent.py.
STEP 2 Intent Router Classifies Query
agent_router.py
Query is classified into 1 of 5 intents and the tool list is pruned to only what's needed:
TIMING"When will X happen?" ← your query
TRANSIT"How are transits today?"
BIRTH_CHART"Show my chart"
COMPATIBILITY"Are we compatible?"
GENERAL"Tell me about Saturn"
STEP 3 Chart Loader
ai_agent.py → @tool get_birth_chart()
Loads saved chart from SQLite (load_chart(session_id)). If none exists, asks DOB / time / location and runs calculate_chart_with_object().

STEP 7 Reconciliation Hub
synthesis_engine.py
Arbitrates cross-tradition conflicts — Parashari vs Jaimini vs KP — into typed evidence triples {subject, domain, polarity, strength}. Verdict: CONTRADICTION = LLM gets both sides, no fake certainty.
STEP 8 Final Output — Dual Channel
✓ Online (LLM available)Pre-computed JSON bundle + system prompt → LLM translates verified math into natural-language reading with exact date windows.
⚡ Offline fallbackdeterministic_formatter.py emits a structured markdown report instantly — zero hallucination, zero API dependency.
THE ONE RULE:  The LLM never does math, never looks up rules, never invents dates.
It only translates pre-computed, verified evidence into human language — hallucination is structurally impossible.
